# C01_Face Keeper

アバタールート（VRC Avatar Descriptor のある GameObject）に 1 つだけ付けるコンポーネントです。設定ウィンドウで有効にする必要はありません。

00_Blendshape Keeper の後継です。表情を再生した瞬間に顔の改変が戻るのを、アップロードのときに防ぎます。表情アニメーションのキー値がブレンドシェイプの今の値より小さければ、今の値まで引き上げます。

必要なもの: **NDMF 1.14.0 以降（2.x は未対応）、VRChat SDK - Base 3.5.0 以降**。Modular Avatar を入れていれば NDMF も入っています。

| 比べるもの | 00_Blendshape Keeper | PAT Face Keeper |
|---|---|---|
| かける相手 | Project で選んだクリップ | アバターの全アニメーション。FaceEmo や Modular Avatar で入れた表情も含む |
| いつ | 「適用」を押したとき | アップロードのたび |
| 元のアニメーション | 書き換えるか、別名で保存する | 書き換えない |
| 表情を作り直したとき | かけ直す | 何もしなくてよい |

## 使い方

1. アバタールートを選び、Add Component の「Poyo's Avatar Toolbox > PAT Face Keeper」を追加します。
2. 「顔のメッシュ」に、顔のメッシュが見つかっていることを確かめます。見つからなければ「自分で指定する」を付け、リストの + で行を足してメッシュを入れます。
3. 表情で値を下げたいブレンドシェイプは、「引き上げないブレンドシェイプ」でチェックを入れます。
4. 「一覧を作る」を押し、値が変わる表情とキーを確かめます。
5. 表情の「プレビュー」で、引き上げ前・引き上げ後を見比べます。

自動では VRC Avatar Descriptor の口と、まぶたの設定からメッシュを見つけます。顔・舌・涙などが別メッシュなら、「自分で指定する」で複数登録できます。除外する名前は完全一致で、登録した全メッシュに共通して使われます。

## 引き上げないブレンドシェイプ

顔のメッシュの折りたたみを開くと、`---brow---` のような区切りごとにブレンドシェイプが並びます。区切りの折りたたみを開き、引き上げないものにチェックを入れてください。並びはメッシュの並びのままです。

区切りの行の ON / OFF で、その中のチェックをまとめて切り替えられます。どの顔のメッシュにも無い名前は「見つからない名前」に出ます。不要ならチェックを外してください。

## 表情の一覧とプレビュー

表情はメニューの階層に沿って並びます。値が変わる表情がないメニューは出ません。メニューに結び付かない表情は、「メニューにない表情」の下に並びます。

表情を選ぶと、変わるキーのメッシュ名・ブレンドシェイプ名・時刻・引き上げ前後の値が出ます。「プレビュー」では左右に並べる比較と、前後の切り替えができます。顔と全身の表示、表情、時刻を選び、視点も動かせます。

!!! note "一覧は押したときの状態です"
    一覧を作るときは、アバターのビルドを 1 回流すので時間がかかります。設定や表情を変えたら、もう一度「一覧を作る」を押してください。作り直すとプレビューは閉じます。

## 制限と注意

- 元のアニメーションは書き換えません。00_Blendshape Keeper で書き換えたクリップも、そのまま使われます。
- 00_Blendshape Keeper と同時に使えます。すでに引き上げたキーは変わりません。
- 今の値より大きいキーは変わりません。値は 0〜100 の範囲に丸めません。
- プレビューはアバターの複製を表示します。シーンのアバターは変更しません。ビルドのときに場所が変わった対象の曲線は、プレビューに出ないことがあります。

## よくある症状

| 症状 | 対処 |
|---|---|
| 「顔のメッシュが見つかりません」と出る | 「自分で指定する」を付け、顔の Skinned Mesh Renderer を入れてください |
| 「2 つ以上あります」と出る | アバター全体で PAT Face Keeper を 1 つにしてください |
| 「引き上げるキーがありませんでした」と出る | 今の値より小さいキーがありません。除外した名前や、対象メッシュも確かめてください |
| 下げたいブレンドシェイプまで戻る | 「引き上げないブレンドシェイプ」で、その名前にチェックを入れてください |
