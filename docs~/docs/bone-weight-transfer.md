# C02_Bone Weight Transfer

衣装の Skinned Mesh Renderer と同じ GameObject に付けるコンポーネントです。設定ウィンドウで有効にする必要はありません。

05_Bone Weight Collapser の後継です。袖が指ボーンに引きずられる、といった問題を、アップロードのときにウェイトを別のボーンへ移して止めます。

必要なもの: **NDMF 1.14.0 以降（2.x は未対応）**

| 比べるもの | 05_Bone Weight Collapser | PAT Bone Weight Transfer |
|---|---|---|
| 結果 | 新しいメッシュを書き出して差し替える | アップロードのときに複製して移す。メッシュのファイルは作らない |
| 衣装の FBX を更新したとき | 書き出したメッシュは古いまま | 更新されたメッシュから移し直す |
| 設定 | ウィンドウで指定する | コンポーネントに残る |

## 使い方

1. 衣装の Skinned Mesh Renderer がある GameObject を選び、Add Component の「Poyo's Avatar Toolbox > PAT Bone Weight Transfer」を追加します。
2. 規則に転移元と転移先を入れます。袖を指に追従させたくない場合は、衣装側の指のボーンを転移元、手首のボーンを転移先にします。
3. 「影響を確認」を押し、影響を受ける頂点数・移すウェイトの総量・規則ごとの内訳を確かめます。
4. 「見た目で確かめる」の操作や Play Mode のハンドサインで、袖の動きを確かめます。

「影響を確認」は統計だけを調べます。メッシュもシーンも変更しません。

## 規則

| 設定 | 内容 |
|---|---|
| 直接指定 | 転移元の Transform を並べます。空の行は無視します |
| 子孫 | 起点の下にあるボーンを転移元にします。「起点自身も含める」で起点も対象にします |
| 転移先 | 移したウェイトを受けるボーンを 1 つ指定します |
| 移す割合 | 0〜1。1 なら全量、0.5 なら半分を移します |
| 正規化 | すべての規則を処理したあと、頂点ごとのウェイトの合計を 1 にします |

規則は上から順に処理します。前の規則で移したウェイトも、次の規則の対象になります。転移先が転移元にも含まれる場合は、転移元から除きます。

規則と転移元はリストの + で足し、− で削除します。並べ替えはドラッグです。複製するには規則を選び、+ のメニューの「選んでいる規則を複製」を押してください。最後の 1 件は削除できません。「該当なし」は、その転移元がウェイトを持っていなかったことを表します。

## 見た目で確かめる

1. 「影響する頂点を表示」を ON にし、ウェイトが移る頂点の黄〜赤の点が、ねらった場所にあるか確かめます。
2. 「曲げて確かめる」を動かし、転移元のボーンを回します。
3. 「移したあとの形で表示」を OFF / ON に切り替えます。ON のときにメッシュが付いてこなければ、ウェイトが移っています。

!!! note "確認中の表示"
    「移したあとの形で表示」は、NDMF のプレビューが有効なときに働きます。「曲げて確かめる」は表示だけで、ボーンの角度は保存されません。スライダーを 0 に戻すと元に戻ります。Animation ウィンドウのプレビュー中は使えません。

## 制限と注意

- 元のメッシュは書き換えません。アップロードのときに複製したメッシュだけを変更します。
- メッシュのファイルは作りません。衣装の FBX を更新しても、設定が使えるボーン構成なら移し直されます。
- ボーンは名前ではなく、指定した Transform で対応付けます。転移元・転移先はそのメッシュのボーン一覧にあるものを選んでください。

!!! note "以前に書き出したメッシュを使っている場合"
    05_Bone Weight Collapser で書き出したメッシュに差し替えたままなら、そのメッシュから移します。衣装の元のメッシュを使いたい場合は、Skinned Mesh Renderer のメッシュを戻してください。

## よくある症状

| 症状 | 対処 |
|---|---|
| 「規則 N は使われません」と出る | 理由を確認してください。転移先がそのメッシュのボーン一覧に無い場合は、衣装側のボーンを指定します |
| 「ウェイトが移る頂点がありませんでした」と出る | 転移元がウェイトを持っているか、割合が 0 になっていないか確かめてください |
| 「適用できる規則がありません」と出る | 転移元と転移先を指定し、少なくとも 1 件の規則を使える状態にしてください |
| 「移したあとの形で表示」を切り替えても見た目が変わらない | まず「曲げて確かめる」を動かしてください。曲げていないと違いは出ません。NDMF のプレビューが有効かも確かめてください |
