# C00_Animation Helper

アバターの中の、動かしたいオブジェクト自身か空の GameObject に付けるコンポーネントです。設定ウィンドウで有効にする必要はありません。同じ GameObject に複数付けられます。

位置・回転・大きさやブレンドシェイプを動かすメニューを、値を入れるだけで作ります。連続して値を変える Radial Puppet と、決めた時間をかけて動くトグルを使えます。

必要なもの: **Modular Avatar 1.17.0 以降**

## トグルを作る

1. GameObject を選び、Add Component の「Poyo's Avatar Toolbox > PAT Animation Helper」を追加します。
2. 種類を「トグル」にし、「動かすもの」のリストの + で行を足します。
3. 対象と動かすものを選び、開始値・終了値・時間を入れます。たとえば大きさを 0 から 1 にすると、ON にしたときに大きくなって現れます。
4. Play Mode と Gesture Manager でメニューを操作し、動きを確かめます。

リストの行はドラッグで並べ替え、− で削除できます。

「初期状態」が OFF なら開始値、ON なら終了値で始まります。「逆も有効」を付けると、OFF にしたときに逆向きに動きます。付けなければ開始値へすぐに戻ります。

## Radial Puppet を作る

種類を「Radial Puppet」にし、行ごとに下限・上限・初期値を入れます。位置・回転・大きさはローカルの値です。回転は度数で指定します。

パラメーターの初期値は先頭の行の初期値で決まります。ほかの行もスライダーの下端で下限、初期位置で初期値、上端で上限になります。

## 設定

| 設定 | 内容 |
|---|---|
| 種類 | トグルか Radial Puppet |
| 名前・アイコン | メニューに表示する名前と画像。名前が空なら GameObject の名前 |
| メニューの挿入先 | 空ならメニューの最上位。サブメニューの MA Menu Item（子のメニューを使う設定）を入れると、その中に入る。ビルド時に MA Menu Item（挿入先が空なら MA Menu Installer も）を自動で付ける |
| パラメーターの名前 | 空なら自動。自分で名前を入れると、ほかの設定と同じパラメーターを使える |
| 値を保存する | アバターを変えても値を保存する |
| 他の人に同期する | メニューの値をほかの人へ同期する |
| 初期状態 | トグルを OFF / ON のどちらで始めるか |
| 時間（秒） | トグルの動く時間。0.01〜10 秒 |
| 動き方 | 一定の速さ、ゆっくり止まる、ゆっくり始まってゆっくり止まる |
| 逆も有効 | OFF にしたときに逆向きに動かす |
| 動かすもの | 対象と、位置・回転・大きさ・ブレンドシェイプの値。「今の値」で対象の値を取り込める |

## 制限と注意

!!! note "動いている途中の切り替え"
    途中で ON / OFF を切り替えても、最後まで動いてから次へ進みます。

!!! warning "保存した値で始めるとき"
    「値を保存する」が ON のトグルは、読み込んだ直後に 1 回動くことがあります。読み込み時に動かしたくなければ OFF にしてください。毎回「初期状態」から始まります。

- Humanoid のボーンは位置と回転を動かせません。大きさは動かせます。
- GameObject の表示・非表示は扱いません。Modular Avatar の Object Toggle を使ってください。
- アップロードのときに Modular Avatar の設定に変わります。元の FX やアニメーションは書き換えません。
- 同じものを複数の行で動かすと、後の行の値が使われます。
- 顔のブレンドシェイプを下げるメニューは、[C01_Face Keeper](face-keeper.md) が引き上げて打ち消すことがあります。その名前を Face Keeper の「引き上げないブレンドシェイプ」に入れてください。

## よくある症状

| 症状 | 対処 |
|---|---|
| 「初期状態の値が、今の見た目と違います」と出る | アップロード直後は設定した値で始まります。見た目をそろえたいときは、初期状態側の「今の値」を押してください |
| Humanoid のボーンの誤りが出る | 位置・回転の行を外すか、ボーン以外の対象へ変えてください |
| メニューが出ない | アバターの中に置いているか、NDMF の画面に誤りが出ていないか確かめてください |
| Radial Puppet を回しても変わらない（トグルは動く） | Write Defaults が OFF のアバターでは、FX のレイヤーに Motion が空（None）のステートがあると起きます。そのステートに中身の無いアニメーションを入れてください |
