# 困ったときは

各ツールに固有のことは、それぞれのページの「よくある質問」にあります。

## メニューに `Tools > Poyo's Avatar Toolbox` が無い

パッケージが入っていません。[インストール](install.md)を確かめてください。VCC で追加したときは、プロジェクトを開き直すと出ます。

## ツールのメニューが無い

ツールごとのメニューはありません。設定ウィンドウでツールを選び、「開く」を押してください。

## チェックを入れたのにツールを開けない

「適用」を押していないか、再コンパイルが終わっていません（[設定ウィンドウ](settings.md)）。

## 「必要なパッケージがありません」と出る

設定ウィンドウの下部に、必要なパッケージとバージョンが出ます。それを入れてください。

## 有効にしたツールが無効になった

そのツールに必要なパッケージを外すと、ツールはコンパイルされなくなります。パッケージを入れ直せば、また使えます。それでも無効なときは、設定ウィンドウでチェックを入れ直して「適用」を押してください。

## ボタンが押せない

ボタンの近くに理由が出ます。どのツールも、再生中は使えません。00_Blendshape Keeper は、Animation ウィンドウでプレビューしている間も使えません。

## 適用した変更を取り消したい

ほとんどの変更は Undo（Ctrl+Z）で取り消せます。次のものは取り消せません。

| 操作 | 扱い |
|---|---|
| 新しく作ったファイル（複製したマテリアル・アニメーション、テクスチャ、LUT、マスク、メッシュ、バックアップ） | 残ります。不要なら Project ウィンドウから削除してください |
| 04_Hair Tone Matcher の焼き直し | 取り消せません |
| 08_FaceEmo Splitter の Prefab の書き換え | 取り消せません |

Unity を再起動したり、スクリプトが再コンパイルされたりすると、Undo の履歴は消えます。

## ファイルが増える

同じ名前のファイルがあるときは、番号を付けた名前で保存して、元のファイルを上書きしません。そのため、繰り返し適用するとファイルが増えます。要らないものは削除してください。同じファイルを更新したいときは、上書きのモードがあるツールではそれを使ってください。

## 報告する

不具合は [GitHub Issues](https://github.com/Poyotoron/Avatar-Toolbox/issues) に送ってください。次のものがあると調べやすくなります。

- Unity のバージョン
- Poyo's Avatar Toolbox のバージョン（設定ウィンドウの上部に出ます）
- 関係するパッケージのバージョン
- ウィンドウや Console に出たメッセージ
- 何をしたときに起きたか

## コンポーネントが Add Component に出ない

必要なパッケージが入っているか、[コンポーネントの一覧](index.md)で確かめてください。設定ウィンドウで有効にする操作は不要です。

## アップロードしたアバターでコンポーネントが効いていない

コンポーネントがアバターの中にあるか、NDMF の画面に誤りが出ていないか確かめてください。PAT Face Keeper はアバタールートに、PAT Bone Weight Transfer は対象の Skinned Mesh Renderer と同じ GameObject に付けます。
